# الخصوصية والحماية | Privacy & Security

## 1. المبدأ

صور الوجوه والتمثيلات الرقمية (embeddings) بيانات بيومترية حساسة. التطبيق مبني على ثلاث قواعد:

1. **كل شيء محلي.** لا يوجد كود شبكة في مسار التحليل: لا رفع صور، لا مفاتيح API، لا تحليلات.
2. **أقل قدر من التخزين.** تُحفظ الصور التي أضافها المستخدم فقط + صورة الاستعلام المرتبطة بسجل بحث.
3. **حذف حقيقي.** حذف السجل يحذف الملف والتمثيل المشفّر معه، لا يُخفيه فقط.

## 2. الصلاحيات والغرض منها

| الصلاحية | الغرض | ملاحظة |
|---|---|---|
| `CAMERA` | التقاط صورة للتحليل عند طلب المستخدم | لا استخدام في الخلفية، تُطلب وقت الحاجة فقط |
| `INTERNET` | غير مستخدمة في التحليل | مذكورة للمستقبل (تنزيل نماذج اختياري)؛ لا يوجد أي نداء شبكة اليوم |
| — | لا صلاحية تخزين | الاختيار عبر **Android Photo Picker** يمنح قراءة الصورة المختارة فقط |

## 3. كيف تُحمى البيانات

| البيانات | الحماية |
|---|---|
| التمثيل الرقمي (128D) | **AES-256-GCM** بمفتاح داخل `AndroidKeyStore` (غير قابل للتصدير)، تُخزَّن `IV ‖ ciphertext` |
| قاعدة البيانات | `allowBackup=false` + `dataExtractionRules` تستثني كل شيء من النسخ السحابي والنقل بين الأجهزة |
| صور الوجوه | مساحة التطبيق الخاصة (`filesDir`)، غير متاحة لتطبيقات أخرى |
| سجلات البحث | تخزين التقرير الكامل؛ حذف السجل يحذف صورة الاستعلام |
| سجلات الأخطاء | لا تُكتب أي بيانات وجه أو إحداثيات أو تمثيلات |

### ما يحمي منه التشفير فعليًا — وما لا يحمي

* **يحمي:** نسخ ملفات قاعدة البيانات من الجهاز، النسخ الاحتياطي عبر adb، قراءة تطبيق آخر
  للتخزين الخاص على جهاز مُروّت.
* **لا يحمي:** من ينفّذ كودًا داخل عملية التطبيق نفسه والجهاز مفتوح (المفتاح قابل للاستخدام حينها).

هذا مذكور صراحة كي لا يُفهم أنه حماية مطلقة.

## 4. حدود المسموح في الاستخدام

التطبيق **لا** يفعل ولا يوفّر:

* جمع صور من الإنترنت أو من حسابات التواصل الاجتماعي.
* البحث عن هوية شخص مجهول في قاعدة بيانات عامة.
* أي مطابقة خارج مجموعة الصور التي أضافها المستخدم بنفسه (المصرّح باستخدامها).
* رفع أي بيانات إلى خادم.

ويُذكّر في الواجهة (شاشة النتائج + المعلومات) بأن **درجة التشابه ليست دليلًا قاطعًا على الهوية**
وأن أي نتيجة تحتاج مراجعة بشرية.

## 5. حقوق المستخدم (منفّذة)

| الحق | مكان التنفيذ |
|---|---|
| حذف صورة مسجّلة وتمثيلاتها | «إدارة قاعدة الصور» → أيقونة الحذف |
| حذف سجل بحث وصورته | «السجل» → أيقونة الحذف |
| حذف كل البيانات | شاشة المعلومات → «حذف كل بيانات التطبيق» |
| معرفة النموذج وعتبته ومصدره | شاشة المعلومات (الترخيص، SHA-256، عتبة المطابقة، AUC/EER المقاس) |
| معرفة حدود النظام | شاشة المعلومات + `README.md` + `docs/EVALUATION.md` |

## 6. ما ينبغي فعله عند النشر الفعلي

هذه نسخة أكاديمية. قبل أي نشر حقيقي لبيانات أشخاص:

1. الحصول على **موافقة صريحة ومكتوبة** من كل شخص صورته في قاعدة البيانات.
2. إعلام المستخدمين بأن النظام لا يصلح كدليل هوية منفرد.
3. التحقق من الالتزام بقوانين حماية البيانات المحلية (مثل GDPR/نظام حماية البيانات الشخصية).
4. إعادة معايرة العتبة على صور من بيئة الاستخدام الحقيقية، لا على LFW وحدها.
